# YOLO-Agent 项目分析报告

## 一、项目概述

YOLO-Agent 是一个工业缺陷检测与分析系统，结合 **YOLOv8** 进行缺陷检测和 **Qwen2-VL** 进行智能分析，实现从图像输入到专业分析报告的完整流程。

***

## 二、核心文件职责分析

**功能定位**：项目启动脚本，负责环境准备和服务启动

**设计特点**：

- 隔离环境配置与业务逻辑

| `/api/analyze_image`   | POST | 图片内容分析       |

| `/api/ask`             | POST | 智能问答         |
| `/api/get_knowledge`   | POST | 获取缺陷知识库信息    |
| `/uploads/<filename>`  | GET  | 访问上传文件       |
| `/reports/<filename>`  | GET  | 访问报告文件       |

**核心流程**：`/api/upload` 路由处理

```python
def upload_file():
    # 1. 文件校验
    # 2. 保存上传文件（UUID标识）
    # 3. 调用 run_pipeline(image_path) ← 核心检测逻辑
    # 4. 缓存分析结果到 analysis_cache
    # 5. 格式化并返回结果（包含决策类型和是否需要人工确认）
```

**决策机制**（新增）：

| 决策类型     | 触发条件             | 说明           |
| -------- | ---------------- | ------------ |
| `auto`   | 高置信度(>0.6)或中/低风险 | 自动决策，无需人工干预. |
| `manual` | 低置信度(<=0.6)且高风险  | 需要人工确认       |

**自动决策规则**：

- 高风险缺陷 > 0 → 判定为不合格 (reject)
- 中等风险缺陷 > 2 → 建议复检 (review)
- 其他 → 判定为合格 (accept)

**关键设计**：

- 使用 UUID 生成唯一文件标识
- 通过 `yolo_qwen_pipeline.py` 解耦检测逻辑
- 使用 `analysis_cache` 缓存分析结果，支持后续确认和决策
- 返回标准化 JSON 格式响应，包含决策建议

### 3.2 核心检测管道 - yolo\_qwen\_pipeline.py

**模型加载策略**：

```python
def load_models():
    # 1. 加载 YOLO 检测模型
    yolo_model = YOLO(YOLO_MODEL_PATH)
    
    # 2. 加载 Qwen2-VL 视觉语言模型
    processor = AutoProcessor.from_pretrained(QWEN_BASE_MODEL, trust_remote_code=True)
    qwen_model = Qwen2VLForConditionalGeneration.from_pretrained(
        QWEN_BASE_MODEL,
        torch_dtype=torch.bfloat16,
        device_map="auto",
        trust_remote_code=True
    )
    
    # 3. 可选加载 LoRA 微调权重
    if QWEN_LORA_PATH and os.path.exists(QWEN_LORA_PATH):
        qwen_model = PeftModel.from_pretrained(qwen_model, QWEN_LORA_PATH)
    
    qwen_model.eval()
    return yolo_model, qwen_model, processor
```

## 四、Qwen 微调状态分析

### 4.1 当前线上状态

**结论**：项目支持 Qwen 微调，但当前线上服务未启用微调权重。

**关键证据**（yolo\_qwen\_pipeline.py 第 20 行）：

```python
QWEN_LORA_PATH = ""  # 如有微调权重请填写
```

由于 `QWEN_LORA_PATH` 为空字符串，以下条件判断为 False：

```python
if QWEN_LORA_PATH and os.path.exists(QWEN_LORA_PATH):
    qwen_model = PeftModel.from_pretrained(qwen_model, QWEN_LORA_PATH)
```

因此，当前服务使用的是 **原始 Qwen2-VL-2B-Instruct 基础模型**，未加载任何 LoRA 微调权重。

### 4.2 项目中的微调能力

项目包含完整的 LoRA 微调基础设施：

| 文件                              | 功能描述                      |
| ------------------------------- | ------------------------- |
| `train_qwen_vl_lora.py`         | Qwen-VL 完整 LoRA 微调（检测+分析） |
| `train_qwen_vl_minimal.py`      | Qwen-VL 极简微调（仅检测定位）       |
| `run_qlora/run_qlora.py`        | QLoRA 4-bit 量化微调          |
| `run_qlora/run_qlora_simple.py` | 简化版 QLoRA 微调（调试用）         |

**已生成的微调模型**：

- `qwen_detection_lora_final/final/` - 完整 LoRA 微调模型
- `qwen_detection_minimal/final/` - 极简版微调模型
- `qlora_500steps_output/` - QLoRA 训练输出检查点

### 4.3 启用微调的方法

如需使用微调后的 Qwen 模型，只需修改 `yolo_qwen_pipeline.py`：

## 五、知识库模块 - knowledge\_base.py（新增）

### 5.1 功能定位

知识库模块提供 RAG（Retrieval-Augmented Generation）检索能力，为 Qwen2-VL 模型提供企业缺陷标准和历史相似案例支持，提升分析准确性。

### 5.2 数据库结构

**企业缺陷标准数据库**：

| 缺陷类型             | 名称     | 判定标准                 | 严重等级 |
| ---------------- | ------ | -------------------- | ---- |
| crazing          | 发丝纹    | 长度超过50mm或宽度超过0.5mm   | 中    |
| inclusion        | 夹杂     | 单个面积超过10mm²或单位面积超过3个 | 高    |
| patches          | 斑块     | 面积超过板面积的1%           | 中    |
| pitted\_surface  | 麻点     | 深度超过0.3mm或密度超过5个/cm² | 低    |
| rolled-in\_scale | 氧化铁皮压入 | 单个压入点面积超过5mm²        | 中    |
| scratches        | 划痕     | 深度超过0.2mm或长度超过100mm  | 低    |

**历史相似案例数据库**：

每个缺陷类型包含多个历史案例，每个案例包含：

- `case_id`：案例编号
- `title`：案例标题
- `description`：案例描述（缺陷成因分析）
- `solution`：解决方案
- `similarity`：相似度评分

### 5.3 RAG检索函数

| 函数                                       | 功能                  |
| ---------------------------------------- | ------------------- |
| `rag_search_standard(defect_type)`       | 检索企业缺陷标准，返回结构化信息    |
| `rag_search_cases(defect_type, top_k=2)` | 检索历史相似案例，按相似度排序     |
| `get_standard_text(defect_type)`         | 获取企业标准文本，用于构造Prompt |
| `get_cases_text(defect_type)`            | 获取历史案例文本，用于构造Prompt |

### 5.4 核心逻辑

```python
def rag_search_standard(self, defect_type):
    """RAG检索企业缺陷标准"""
    if defect_type in self.enterprise_standards:
        info = self.enterprise_standards[defect_type]
        return {
            'found': True,
            'name': info['name'],
            'description': info['description'],
            'standard': info['standard'],
            'severity': info['severity'],
            'source': info['source']
        }
    return {'found': False, 'message': '未找到相关企业标准'}

def rag_search_cases(self, defect_type, top_k=2):
    """RAG检索历史相似案例"""
    if defect_type in self.historical_cases:
        cases = sorted(self.historical_cases[defect_type], 
                      key=lambda x: x['similarity'], reverse=True)[:top_k]
        return {'found': True, 'cases': cases, 'count': len(cases)}
    return {'found': False, 'cases': [], 'count': 0}
```
