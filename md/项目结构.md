## 目录说明

| 目录/文件 | 说明 |
|----------|------|
| `backend/` | 包含 Flask 后端服务代码，负责图片处理、YOLO 检测、知识库查询和报告生成 |
| `frontend/` | 前端 Web 界面，基于 HTML/CSS/JavaScript 实现 |
| `NEU-DET/` | 钢铁表面缺陷数据集，包含 6 类缺陷：裂纹(crazing)、夹杂(inclusion)、斑块(patches)、点蚀(pitted_surface)、轧制氧化皮(rolled-in_scale)、划痕(scratches) |
| `ultralytics-8.0/` | Ultralytics YOLOv8 源码目录，包含训练脚本、预测脚本和模型配置 |
| `runs/` | YOLO 模型训练输出目录，包含训练好的模型权重和参数配置 |
| `prepare_data.py` | 数据准备脚本，用于处理和转换数据集格式 |
| `convert_yolo_to_qwen.py` | YOLO 标注转 Qwen VL 格式脚本，生成多模态微调数据 |
| `qwen_finetune_data.jsonl` | Qwen VL 7B 多模态模型微调数据（JSONL格式），包含钢铁表面缺陷检测的图像-文本对 |
| `uploads/` | 用户上传的原始图片存储目录 |
| `static/` | 检测结果图片存储目录 |
| `reports/` | 生成的 HTML 分析报告存储目录 |
| `models/` | YOLO 模型权重文件存储目录 |

## 缺陷类型

本项目支持检测的工业缺陷类型包括：

| 缺陷类型 | 英文名 | 描述 |
|---------|--------|------|
| 划痕 | Scratches | 物体表面被尖锐物体划过留下的痕迹 |
| 裂纹 | Crazing | 材料内部或表面出现的裂缝 |
| 凹陷 | Pitted Surface | 物体表面向内凹陷的缺陷 |
| 凸起 | Patches | 物体表面向外突出的缺陷 |
| 腐蚀 | Inclusion | 材料与周围环境发生化学反应导致的损坏 |
| 磨损 | Rolled-in Scale | 物体表面因摩擦导致的材料损失 |
| 变形 | Pitted | 物体形状发生非预期的改变 |
| 污渍 | - | 物体表面附着的污染物 |
| 气泡 | - | 材料内部或表面形成的气体空隙 |
| 断裂 | - | 材料发生完全分离的严重缺陷 |

## 快速启动

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 下载 YOLO 模型到 models/ 目录
# 3. 进入后端目录并启动服务
cd backend
python app.py

# 4. 访问 http://localhost:5000
```
