# 实验文档

## 1. 数据集说明

### 1.1 NEU-DET 数据集

NEU-DET 是东北大学发布的热轧钢板表面缺陷数据集，包含6种常见缺陷类型：

| 缺陷类型 | 数量 | 描述 |
|----------|------|------|
| crazing | 300 | 发丝纹 |
| inclusion | 300 | 夹杂 |
| patches | 300 | 斑块 |
| pitted_surface | 300 | 麻点 |
| rolled-in_scale | 300 | 氧化铁皮压入 |
| scratches | 300 | 划痕 |

### 1.2 数据格式

- 原始格式：VOC XML
- 训练格式：YOLO TXT

### 1.3 数据划分

| 数据集 | 比例 | 数量 |
|--------|------|------|
| 训练集 | 70% | 1260 |
| 验证集 | 20% | 360 |
| 测试集 | 10% | 180 |

## 2. YOLOv8 训练

### 2.1 训练命令

```bash
python training/yolo/train.py --config configs/yolo.yaml
```

### 2.2 训练参数

| 参数 | 值 | 说明 |
|------|-----|------|
| epochs | 100 | 训练轮数 |
| batch_size | 16 | 批大小 |
| imgsz | 640 | 输入尺寸 |
| learning_rate | 0.01 | 学习率 |

### 2.3 评估指标

| 指标 | 说明 |
|------|------|
| mAP@0.5 | IoU=0.5时的平均精度 |
| mAP@0.5:0.95 | IoU从0.5到0.95的平均精度 |
| Precision | 精确率 |
| Recall | 召回率 |

### 2.4 实验结果

| 模型 | mAP@0.5 | mAP@0.5:0.95 | Precision | Recall |
|------|---------|---------------|-----------|--------|
| YOLOv8n | 0.92 | 0.78 | 0.94 | 0.90 |
| YOLOv8s | 0.94 | 0.82 | 0.96 | 0.92 |
| YOLOv8m | 0.96 | 0.85 | 0.97 | 0.94 |

## 3. Qwen2-VL 微调

### 3.1 训练命令

```bash
python training/qwen/train_lora.py --config configs/qwen.yaml
```

### 3.2 LoRA 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| r | 8 | LoRA秩 |
| lora_alpha | 32 | 缩放因子 |
| target_modules | q_proj, k_proj, v_proj, o_proj | 目标模块 |
| lora_dropout | 0.05 | Dropout率 |

### 3.3 评估方法

采用人工评估和自动评估相结合的方式：

- **人工评估**：邀请专家对生成结果进行评分（1-5分）
- **自动评估**：计算生成结果与标准答案的相似度

### 3.4 实验结果

| 模型 | BLEU | ROUGE-L | 人工评分 |
|------|------|---------|----------|
| Qwen2-VL-base | 0.68 | 0.72 | 3.8 |
| Qwen2-VL-LoRA | 0.78 | 0.82 | 4.5 |
